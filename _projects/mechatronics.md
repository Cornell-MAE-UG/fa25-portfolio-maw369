For our MAE 3780 final robot project, we designed and built an autonomous robot to collect and clear cubes from a competition board. Our robot used QTI line sensors for black border detection, a servo-driven door mechanism for cube release, and custom 3D printed extensions to increase its collection area. The goal was to combine mechanical design, sensor integration, wiring, and embedded C programming into one working system.

As a team, we divided the project across CAD modeling, coding, wiring, assembly, and testing. I contributed heavily to the CAD design of the chassis extension and door mechanism, while also helping debug the QTI sensors, servo behavior, and robot movement logic. One of the biggest challenges was making the robot reliable under real competition conditions, since small mechanical issues like loose attachments or blocks catching near the edge could affect performance. Through repeated testing and iteration, we improved the robot’s ability to collect blocks, detect the border, turn, and release cubes.

Overall, this project gave me hands-on experience with the full mechatronics design process. It showed me how closely mechanical design, electrical wiring, and code depend on each other, and how important it is to test a robot under realistic conditions before competition.

**My Role:** CAD modeling, chassis extension design, servo/door mechanism integration, QTI sensor debugging, and code testing

**Highlights**
- Designed custom 3D printed chassis extensions and door components
- Programmed robot behavior in embedded C using direct port manipulation
- Integrated QTI sensors for line detection and a servo motor for cube release
- Tested and debugged mechanical, electrical, and software issues before competition

**Key Takeaway:** I gained hands-on experience building a complete mechatronic system where CAD, sensors, actuators, wiring, and code all had to work together reliably.
